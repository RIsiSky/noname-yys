### noname/无名杀—阴阳师扩展
- 以无名杀为基础，依据网易阴阳师手游进行编写的武将扩展。
- 作为阴阳师的牢玩家，在网易反复的背刺玩家、伤害玩家的操作下，在削减奖励、不降肝度的情况下，本人毅然决定退游，但是仍然舍不得痒痒鼠的崽崽们。
- 考虑到本人有一定编程基础且为三国杀资深面杀玩家，决定为痒痒鼠的式神编写无名杀的扩展，同时也感谢无名杀这个开源的平台。
- 扩展包含了三十多位阴势力武将，另外还有几位依据王者和三体编写的武将，由于起初是自用娱乐，因此存在一些作者的私货。
- 欢迎同时喜爱着阴阳师和无名杀的伙伴们一起交流
